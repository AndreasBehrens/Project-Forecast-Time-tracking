Insight Arcs · Time Tracking | User Guide Insight Arcs – Time Tracking & Project Forecast · 2 a) Live Timer (for ongoing activities) Ideal when you start a task now and want the time to run live. 1. Select the "Live Timer" tab. 2. Choose the project and optionally the task. 3. Enter a short description of the activity. 4. Click "Start Timer" – the clock runs. 5. For interruptions: "Pause" (resume later) – paused time is not counted. 6. To finish: "Stop & Save" – the entry is booked. Note: The timer keeps running in the background, even if you reload the page. b) Manual Time Entry (for forgotten / past days) Ideal for adding times that were not stopped live. 1. Select the "Manual Time Entry" tab (labelled "Past Days"). 2. Choose the date. 3. Choose the project and optionally the task. 4. Enter a description. 5. Enter the start time and end time. 6. If needed, enter the break (min) – it is deducted from working time. 7. Click "Save Entry". Billable / Non-billable For every entry, the € symbol determines whether the time is billable: • € (green) = billable (invoiced to the client) • € struck through (grey) = non-billable (e.g. internal activity) The default comes from the project (client project = billable, internal project = non-billable) but can be adjusted per entry. Hover over the symbol to see the current status in your language. Approval workflow (if enabled for a project) If approval is required for a project, your entries first receive the status: • Draft → not yet submitted • Submitted → waiting for approval by the project manager • Approved → reviewed and booked Note: If no approval requirement is set, entries are booked directly as approved. 2.
